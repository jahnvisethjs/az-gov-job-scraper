# Repository Instructions

Before changing this repository, read `CODEBASE_CONTEXT.md` when it exists. It
contains local maintainer context, active decisions, deployment state, and known
shortcomings that cannot be reconstructed reliably from the tracked source.

Keep `CODEBASE_CONTEXT.md` current when work changes architecture, priorities,
deployment assumptions, known risks, or the status of unfinished work. Never
put credentials, API keys, database passwords, resume contents, or other secrets
in that file.

Treat tracked documentation and executable code as the authority for current
implementation details. If `CODEBASE_CONTEXT.md` conflicts with the code,
verify the behavior, correct the context file, and call out the stale entry.
